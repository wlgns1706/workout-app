# 운동 기록 앱 사용법

앱 안의 설정 → 사용법 보기와 같은 내용입니다.

## 1. 처음 설정

1. 설정은 홈 화면 오른쪽 위의 "⚙ 설정" 버튼으로 엽니다. 아래쪽 탭은 홈, 운동, 식단, 몸 상태, 기록입니다.
2. 설정 → "프로그램 또는 백업 파일 가져오기"에서 프로그램 파일을 고릅니다. 묶음 파일(all-programs.bundle.json)을 고르면 근비대 One, 근비대 기본, 스트렝스 One, 스트렝스 기본이 한 번에 들어갑니다.
3. 설정 → "새 일정 만들기"에서 프로그램, 시작일, 블록 순서(예: 1,1,2,3)를 넣고 "일정 만들기"를 누릅니다. 블록 하나는 4주입니다.
4. 설정 → "영양 목표"의 값을 확인하고 "저장"을 누릅니다. 목표는 적용 시작일부터 쓰입니다.

## 2. 홈 화면

1. 맨 위에 결혼식까지 남은 날과 지금 일정 위치가 보입니다.
2. 링 세 개는 목표 체중 진행률, 오늘 칼로리(목표 기준), 이번 주 운동(정규 요일 완료 수)입니다. 링을 누르면 해당 화면으로 갑니다.
3. "오늘 할 일": 체중, 운동, 식단, 주간 측정 중 끝낸 것은 ●로 바뀝니다. 체중은 홈에서 바로 적을 수 있고, 식단 줄에는 남은 칼로리와 단백질이 보입니다.
4. "체중": 7일 평균, 시작 대비 변화, 목표 체중까지의 진행률, 연속 기록 일수, 최근 14일 그래프가 보입니다. 목표 체중은 설정에서 정합니다.
5. "운동과 식단" 달력: ✓는 운동을 완료한 날, ●는 식단을 지킨 날, ○는 식단만 기록한 날입니다. 날짜를 누르면 그날의 운동과 식단 합계가 보입니다. 아래에 그 달의 운동 일수와 지킨 날 수가 나옵니다.
6. "최근 PR": 최근 14일 안에 추정 1RM 최고 기록을 넘은 종목이 보입니다.

## 3. 운동 기록

1. 아래쪽 "운동" 탭을 누르면 이번 주 요일과 다음에 할 운동이 보입니다. 큰 "D○ 시작" 버튼을 누르거나 요일(D1~D6)을 눌러 엽니다. 홈의 오늘 할 일에서 운동 줄을 눌러도 됩니다.
2. 위쪽 "전체 2/16주 · 블록 1의 2주차 · RPE 7 주간"은 전체 일정 중 몇 번째 주인지, 블록 안에서 몇 번째 주인지, 이번 주 강도를 뜻합니다. 종목 이름 아래 초록 글씨(예: 2세트 × 8~12회 · RPE 7)가 그 종목의 오늘 목표입니다.
3. 종목 이름 옆에 ⇄가 있으면 대체 운동이 있습니다. 이름을 누르면 엑셀에 정해진 대체 운동 목록이 뜨고, 고른 종목은 오늘 그 요일에만 적용됩니다. 기록은 실제로 한 종목 이름으로 남아서, 지난 기록과 추천 무게도 그 종목 기준입니다.
4. 무게나 횟수를 누르면 팝업이 뜹니다. 무게는 ±0.5, ±5 버튼이나 직접 입력, kg/lbs 전환이 됩니다. 횟수 팝업에서 RPE와 "실패 세트"를 고릅니다.
5. 흐린 숫자는 지난 기록으로 계산한 추천 무게입니다. 그대로 ✓를 누르면 그 값으로 기록됩니다.
6. ✓를 누르면 세트가 기록되고 휴식 타이머가 시작됩니다. 다시 누르면 취소됩니다. ⏱을 누르면 종목별 휴식 시간을 바꿉니다. 타이머는 30초 남았을 때 한 번, 5초 전부터 매초 짧게, 끝날 때 길게 소리를 냅니다. 화면이 꺼져 있으면 소리가 늦을 수 있습니다.
7. 다른 앱으로 넘어가도 휴식 시간을 보려면 처음 타이머가 뜰 때 "알림 켜기"를 누르세요(설정 → 휴식 타이머에서도 켜고 끌 수 있습니다). 폰 알림창에 남은 시간과 끝나는 시각이 5초마다 바뀌고, 30초 전과 끝날 때 진동이 울립니다. 알림을 누르면 앱으로 돌아오고, 앱으로 돌아오면 알림은 사라집니다.
8. 세트 번호를 누르면 노란 W(웜업)로 바뀝니다. 웜업은 추천 무게와 1RM 계산에서 빠집니다.
9. "− 세트 +"로 세트를 더하거나 지웁니다. −는 직접 추가한 세트만 지웁니다.
10. ⋮ 메뉴에서 단위를 바꾸거나, "나중에 하기"로 종목을 맨 아래로 미루거나, "접기"로 카드를 접습니다. 세트를 다 해도 카드는 저절로 접히지 않습니다.
11. "운동 완료"를 누르면 그날 운동이 끝납니다. 못 한 세트는 D5나 D6의 "이번 주에 못 한 운동"에서 이어서 할 수 있습니다.
12. "운동" 탭의 "전체 일정 보기"에서 지난 주 기록을 열어 보거나 고칠 수 있습니다.
13. "운동 완료"를 누르면 오늘 운동 요약이 뜹니다: 운동 시간, 한 세트 수, 볼륨(kg×회), 지난번 같은 요일과의 볼륨 차이, 새 PR, 지난번보다 추정 1RM이 오른 종목. 완료한 요일에서는 "오늘 운동 요약 보기"로 다시 볼 수 있습니다.

## 4. 식단

1. 위쪽 날짜를 누르면 달력이 뜹니다. 초록 점은 식단을 지킨 날, 회색 점은 기록만 한 날입니다.
2. 지킨 날: 칼로리가 목표 범위 안이고 단백질이 최소 이상인 날입니다.
3. 끼니의 ＋를 누르고 음식을 넣습니다. 칼로리를 비우면 탄수화물·단백질 ×4, 지방 ×9로 계산합니다.
4. "자주 먹는 음식으로 저장"을 체크하면 다음부터 목록에 나옵니다. ×0.5~×2로 양을 고른 뒤, "추가"를 누르면 바로 들어가고, 음식 이름을 누르면 아래 입력 칸으로 불러와서 고친 뒤 추가할 수 있습니다.
5. "어제 ○○ 복사"로 어제 같은 끼니를 그대로 가져옵니다.
6. 막대 색: 초록은 목표 범위 안, 회색은 부족, 주황은 초과입니다. 끼니 단백질이 40g보다 적으면 "단백질 부족"이 보입니다.
7. 음식을 누르면 수정하거나 지울 수 있습니다.
8. 음식이나 자주 먹는 음식을 지우면 아래에 "되돌리기"가 6초 동안 뜹니다. 실수로 지웠으면 바로 누르세요.

## 5. 몸 상태

1. "매일 기록": 아침 화장실에 다녀온 뒤 식사 전에 체중을 재서 적습니다. 수면과 컨디션 점수도 적을 수 있습니다.
2. "주간 측정": 주 1회 인바디(체중, 골격근량, 체지방량, 체지방률)와 허리둘레를 적습니다. 같은 기기와 조건에서 재세요.
3. 7일 평균은 최근 7일 중 4일 이상 기록해야 계산됩니다. 하루하루의 체중보다 7일 평균의 변화를 보세요.
4. 2주 연속 감량이 너무 느리거나 빠르면 위쪽에 알림이 뜹니다. 알림은 참고용이고, 목표는 설정에서 직접 바꿉니다. 처음 목표를 저장한 뒤 2주 동안은 알림이 뜨지 않습니다.

## 6. 기록 탭

1. 위쪽에서 기간(4주, 12주, 전체)을 고릅니다.
2. 체중: 흐린 점은 매일 체중, 선은 7일 평균, ◆는 인바디 체중입니다. 빨간 점선은 결혼식 날입니다.
3. 체성분: 골격근량이 유지되면서 체지방량이 줄어드는지 봅니다.
4. 추정 1RM: 종목을 고르면 날짜별 최고 추정 1RM이 보입니다. 초록 점은 최고 기록을 넘은 날입니다.
5. 식단: 막대는 하루 칼로리, 초록 띠는 목표 범위, 아래 선은 단백질입니다.
6. 그래프의 점이나 막대를 누르면 날짜와 값이 위에 표시됩니다.

## 7. 백업과 복원

1. 백업은 언제든 설정(홈 오른쪽 위 ⚙) → 백업 → "백업 내보내기"에서 합니다.
2. 7일 넘게 백업하지 않으면 홈 "오늘 할 일"에 백업 줄이, 다른 화면에는 위쪽 알림이 뜹니다. "지금 백업"을 누르면 바로 공유 창이 열립니다. 공유 창을 닫으면 백업한 것으로 치지 않습니다.
3. 기록은 폰 안에만 저장됩니다. 일주일에 한 번 백업하세요. 7일이 지나면 위쪽에 알림이 뜹니다.
4. 설정 → "백업 내보내기"를 누르면 공유 창이 뜹니다. 구글 드라이브나 카카오톡 "나에게 보내기"를 고르세요. 공유 창이 없으면 내 파일 → 다운로드 폴더에 저장됩니다.
5. 복원: 설정 → "프로그램 또는 백업 파일 가져오기"에서 workout-backup-날짜.txt(예전 백업은 .json)를 고르고 "복원"을 누릅니다. 지금 폰의 기록은 백업 내용으로 바뀝니다.
6. 폰을 바꿀 때: 옛 폰에서 백업 → 새 폰에 앱 설치 → 백업 파일 가져오기 순서입니다.

## 8. 설정과 업데이트

1. 화면 테마: 기본은 다크입니다. "폰 설정 따라가기", "라이트", "다크" 중에서 고를 수 있습니다.
2. 12주(또는 정한 기간)가 끝나면 "새 일정 만들기"로 다음 프로그램을 시작합니다. 이전 기록은 그대로 남습니다.
3. 앱이 새 버전으로 바뀌면 위쪽에 "새 버전이 있어요"가 뜹니다. "지금 갱신"을 누르면 적용됩니다. 기록은 지워지지 않습니다.
4. 설정의 프로그램 목록에 "예전 파일 (대체 운동 없음)"이 보이거나 새 프로그램 파일을 받으면, 설정 → "프로그램 또는 백업 파일 가져오기"로 다시 가져오고 "덮어쓸까요?"에 확인을 누릅니다. 기존 기록은 그대로 남습니다.
